# Working with pages

## Notes about page conventions and discovery:

1. By convention, page template should have prefix "page-". Full name should be "page-{name}.php". 

2. Pages can be placed in theme root folder, or in nested folders, for example "pages" or "templates".

3. To make page template discoverable by WordPress, file should have this content:
```
<?php
/*
Template Name: (put your template name here)
*/
?>
```
